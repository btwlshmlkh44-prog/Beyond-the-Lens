# نسخة الكود المنظمة — Portfolio بتول شملخ

- `index.html`: هيكل الصفحة ومحتواها.
- `styles.css`: أنماط التصميم المستخرجة من HTML.
- `js/`: ملفات JavaScript منفصلة ومحافظة على ترتيب تشغيلها الأصلي.
- `assets/`: صور الأعمال الأصلية، من دون ضغط أو تعديل على محتواها.

للتشغيل محلياً: شغّل خادماً ثابتاً من هذا المجلد (مثلاً `python3 -m http.server 8000`) ثم افتح `http://localhost:8000`.
